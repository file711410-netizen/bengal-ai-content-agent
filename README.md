# bengal-ai-content-agent
My Free AI Agent for Automated Video and Facebook Content Creation
Bengal AI Content Creator Agent

A free-first AI-powered content creation project.

Main Goal

Build an automated AI agent for Facebook Reels and video content creation.

Core Features

- AI Story Generator
- 5-Scene Video Prompt Generator
- Google Flow-ready production prompts
- Image generation workflow
- Video production workflow
- Facebook captions and hashtags
- Content planning and automation

Production Rules

- Explain instructions in Bengali.
- Write production prompts in English.
- Default video format: 9:16 vertical.
- Default structure: 5 scenes, approximately 8 seconds each.
- Maintain strict visual continuity.
- Prefer photorealistic cinematic visuals.
- Never omit required scene sections.

Project Principle

Start with free and open-source tools wherever possible. Never expose API keys or passwords in public files.
